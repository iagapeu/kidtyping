# 키즈 타자교실 (KidTyping)

어린이를 위한 한글·영문 자판 익히기 프로그램입니다. 브라우저에서 바로 실행됩니다.

**바로 하기:** https://iagapeu.github.io/kidtyping/

- 키보드 위 투명한 손 모양으로 칠 손가락과 키를 알려 줍니다.
- 한글 자리연습(왼손·오른손 윗줄·중간줄·아랫줄), 모음 조합, 낱말, 문장, 책 따라치기
- 영어 자리연습, 단어, 문장
- 타수·정확도·연습 시간·점수, 친구(프로필)별 기록과 이어하기
- 게임 4종(풍선 터뜨리기, 두더지 잡기, 낱말 비, 자동차 경주), 한글·영어 각 10단계
- 텍스트(.txt) 파일을 추가해 좋아하는 책을 따라 칠 수 있습니다.

기록은 사용하는 브라우저에 저장됩니다.

제작: 김현철 · 프리웨어(무료) · 블로그: https://blog.naver.com/iagapeu
